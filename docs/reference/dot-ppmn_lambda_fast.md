# Helper function oob fast

Helper function oob fast

``` r
.ppmn_lambda_fast(loss_array, max_lambda, n_rep, n_lambda = 200)
```

## Arguments

- loss_array:

  An array fo losses.

- max_lambda:

  Maximum lambda.

- n_lambda:

  Number of steps for lambda.

- loss:

  Compressed loss per s.

- n_split:

  Number of repetitions.

- ess_frac:
