# Helper function oob fast

Helper function oob fast

## Usage

``` r
.ppmn_lambda_fast(
  loss_array,
  max_lambda,
  n_rep,
  n_lambda = 200,
  ess_frac = 0.05
)
```

## Arguments

- loss_array:

  An array fo losses.

- max_lambda:

  Maximum lambda.

- n_lambda:

  Number of steps for lambda.

- ess_frac:

  Effective sample size boundary.

- loss:

  Compressed loss per s.

- n_split:

  Number of repetitions.
