# Helper MC approx. for mv KL-divergence

Helper MC approx. for mv KL-divergence

## Usage

``` r
.ppmn_resid_mc_kl(resid1, resid0, loss, n_boot = 1000, n_mc = 5000)
```

## Arguments

- resid1:

  Residuals.

- resid0:

  Model prior residuals

- loss:

  Loss.

- n_boot:

  Number of bayesian bootstraps.

- n_mc:

  Number of mc.
