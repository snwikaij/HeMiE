# Plot the emperical cumulative density curves

Plot the emperical cumulative density curves

## Usage

``` r
party_curve(object, taxon = NULL, grid = 50)
```

## Arguments

- object:

  An partitioning object created by party_point.

- taxon:

  Select a taxon name from the assemblage (default is the first).

- grid:

  The size of the grid being interpolated.
