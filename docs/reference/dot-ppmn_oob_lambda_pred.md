# Helper OOB optimizer

Helper OOB optimizer

## Usage

``` r
.ppmn_oob_lambda_pred(obs_mat, loss, max_lambda, seed, seq_len, n_boot = 1000)
```

## Arguments

- obs_mat:

  Observed matrix.

- loss:

  Loss matrix.

- max_lambda:

  Maximum lambda.

- seed:

  seed.

- seq_len:

  Length of lambda sequence.

- n_boot:

  number of bootstraps.
