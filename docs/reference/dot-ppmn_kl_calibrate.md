# Grid approximation for Kullenback-Leibler divergence

Grid approximation for Kullenback-Leibler divergence

## Usage

``` r
.ppmn_kl_calibrate(r_data, r_prior, n_boot = 2000, n_grid, n_samp)
```

## Arguments

- r_data:

  Residuals of the data.

- r_prior:

  Residuals of the prior.

- n_boot:

  Number of bootstraps.

- n_grid:

  Size of the grid.
