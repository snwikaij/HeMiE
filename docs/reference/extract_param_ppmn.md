# Extract parameters from object

This is a simple function that creates a data frame with the point,
lower and upper interval. It also produce two figures of this data frame
so that the change in the estimated parameters can be checked. This
function is build to make your life easier. You do not have to use the
figures, but it makes extraction a bit easier.

## Usage

``` r
extract_param_ppmn(object)
```

## Arguments

- object:

  An updated or foundational PPMN.
