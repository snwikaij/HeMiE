# Package index

## Posterior Predictive Meta-analytic Networks

Functions for constructing, updating, predicting from, and evaluating
Posterior Predictive Meta-analytic Networks.

- [`build_ppmn()`](https://snwikaij.github.io/HeMiE/reference/build_ppmn.md)
  : Build the foundational Posterior Predictive Meta-analytic Network
  (PPMN)
- [`update_ppmn()`](https://snwikaij.github.io/HeMiE/reference/update_ppmn.md)
  : Update PPMN function
- [`predict_ppmn()`](https://snwikaij.github.io/HeMiE/reference/predict_ppmn.md)
  : Predict function for a PPMN object
- [`marginal_ppmn()`](https://snwikaij.github.io/HeMiE/reference/marginal_ppmn.md)
  : Plots the marginal expectations of each edge function with
  credibility intervals
- [`pred_fit_ppmn()`](https://snwikaij.github.io/HeMiE/reference/pred_fit_ppmn.md)
  : Predictive fit function to assess performance
- [`disp_ppmn()`](https://snwikaij.github.io/HeMiE/reference/disp_ppmn.md)
  : Displacement test for PPMN
- [`root_est_ppmn()`](https://snwikaij.github.io/HeMiE/reference/root_est_ppmn.md)
  : Root estimation function
