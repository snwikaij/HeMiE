# Package index

## Generalized Bayesian Meta-analytic Networks

Functions for constructing, updating, predicting from, and evaluating
Generalized Bayesian Meta-analytic Networks.

- [`build_gbmn()`](https://snwikaij.github.io/HeMiE/reference/build_gbmn.md)
  : Build the foundational Generalized Bayesian Meta-analytic Network
  (GBMN)
- [`update_gbmn()`](https://snwikaij.github.io/HeMiE/reference/update_gbmn.md)
  : Update GBMN function
- [`predict_gbmn()`](https://snwikaij.github.io/HeMiE/reference/predict_gbmn.md)
  : Predict function for a GBMN object
- [`marginal_gbmn()`](https://snwikaij.github.io/HeMiE/reference/marginal_gbmn.md)
  : Plots the marginal expectations of each edge function with
  credibility intervals
- [`pred_fit_gbmn()`](https://snwikaij.github.io/HeMiE/reference/pred_fit_gbmn.md)
  : Predictive fit function to assess performance
- [`disp_gbmn()`](https://snwikaij.github.io/HeMiE/reference/disp_gbmn.md)
  : Displacement test for GBMN
- [`extract_covar_gbmn()`](https://snwikaij.github.io/HeMiE/reference/extract_covar_gbmn.md)
  : GBMN correlation matrix extraction
- [`extract_param_gbmn()`](https://snwikaij.github.io/HeMiE/reference/extract_param_gbmn.md)
  : Extract parameters from object

## Example data

Example datasets for constructing, updating, and evaluating GBMNs.

- [`example1`](https://snwikaij.github.io/HeMiE/reference/example1.md) :
  Example meta-analytic data for a single GBMN edge
- [`example2`](https://snwikaij.github.io/HeMiE/reference/example2.md) :
  Example meta-analytic data for a multi-edge GBMN
- [`meta_data`](https://snwikaij.github.io/HeMiE/reference/meta_data.md)
  : Example meta-analytic data for a larger GBMN
- [`train_data`](https://snwikaij.github.io/HeMiE/reference/train_data.md)
  : Example training data for updating a GBMN
- [`val_data`](https://snwikaij.github.io/HeMiE/reference/val_data.md) :
  Example validation data for a GBMN
