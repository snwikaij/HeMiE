# Helper function for Kullenback-Leiber optimizer for lambda

Helper function for Kullenback-Leiber optimizer for lambda

## Usage

``` r
.ppmn_lambda_kl(loss, kl_target, prior = NULL, upper = max_lambda)
```

## Arguments

- loss:

  The loss.

- kl_target:

  KL-divergence target value.

- prior:

  Prior.

- upper:

  Upper boundary for lambda.
