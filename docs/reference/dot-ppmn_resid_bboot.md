# Helper function for Bayesian bootstrap

Helper function for Bayesian bootstrap

## Usage

``` r
.ppmn_resid_bboot(resid1, resid0, n_grid = 3000, n_boot = 1000)
```

## Arguments

- resid1:

  Residuals for particle with best fit.

- resid0:

  Residuals for the prior.

- n_grid:

  Size of the grid.

- n_boot:

  Number of bootstraps.
