# Helper function to summarize the output of different calibration methods

Helper function to summarize the output of different calibration methods

## Usage

``` r
.gbmn_summarize_particles(object, preds, weights, obs_nodes, level, covar)
```

## Arguments

- object:

  An foundational or updated GBMN

- preds:

  Predictions of the GBMN

- weights:

  Weights of the GBMN

- obs_nodes:

  Observed nodes (names)

- level:

  credibility level

- covar:

  return covariance.
