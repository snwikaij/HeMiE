# Predict function for a PPMN object

Predict function for a PPMN object

## Usage

``` r
predict_ppmn(object, new_data, nsim = 1000, seed = 123)
```

## Arguments

- object:

  A foundational or updated PPMN.

- new_data:

  New data for prediction.

- nsim:

  Number of simulations.

- seed:

  Seed value 123.
