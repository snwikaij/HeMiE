# Helper function to Kullenback-Leibler divergence optimizer

Helper function to Kullenback-Leibler divergence optimizer

## Usage

``` r
.ppmn_kl_optim(lambda, loss, kl_target, prior = NULL)
```

## Arguments

- lambda:

  Lambda

- loss:

  Loss

- kl_target:

  KL divergence target

- prior:

  Prior
