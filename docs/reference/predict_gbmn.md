# Predict function for a GBMN object

Predict function for a GBMN object

## Usage

``` r
predict_gbmn(object, new_data, nsim = 1000, seed = 123)
```

## Arguments

- object:

  A foundational or updated GBMN.

- new_data:

  New data for prediction.

- nsim:

  Number of simulations.

- seed:

  Seed value 123.
