# Helper function to calculate loss and residuals

Helper function to calculate loss and residuals

## Usage

``` r
.ppmn_loss_resid(obs_mat, preds, obs_nodes, nsim, mad_constant = 1)
```

## Arguments

- obs_mat:

  Observed values matrix.

- preds:

  Predictions on this observed matrix.

- obs_nodes:

  Observed nodes of the matrix.

- nsim:

  Number of simulations.

- mad_constant:

  Constant.
