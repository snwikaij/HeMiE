# Helper function to generate proposals

Helper function to generate proposals

## Usage

``` r
.gbmn_proposal_particles(object, preds, weights, obs_nodes)
```

## Arguments

- object:

  A foundational or updated GBMN.

- preds:

  Predictions from the GBMN

- weights:

  Weights based on the loss

- obs_nodes:

  Observed nodes/vertices (I am so inconsistent with nodes/vertices).
